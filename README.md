# Django E-Commerce Website

A modern, full-featured E-Commerce platform built with Python & Django.

## 🚀 Features (Planned & Roadmap)
- **User Authentication**: Sign Up, Login, Logout, Profile & Address Management
- **Store & Catalog**: Product listings, categories, detailed product view, search & filters
- **Shopping Cart**: Add to cart, quantity update, session-based cart
- **Checkout & Orders**: Order placement, order summary, order history
- **Payment Gateway**: Cash on Delivery (COD) & Razorpay integration
- **Admin Panel**: Manage products, categories, orders, and users seamlessly

## 🛠️ Tech Stack
- **Backend**: Python 3.11, Django
- **Frontend**: HTML5, CSS3, Bootstrap 5 / JavaScript
- **Database**: SQLite (Development) / PostgreSQL (Production ready)
